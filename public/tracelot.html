TraceLot / BioStock

Traçabilité et sécurisation de la chaîne d'approvisionnement en biomasse

2026 Mobile + Web + IA En développement (MVP)

Solution de traçabilité industrielle pour la centrale thermique ECOR Divo (SODEN, Côte d'Ivoire). Application mobile offline-first, plateforme web de supervision, backend Node.js, et ancrage blockchain pour la conformité ESG et EUDR.

Flutter Dart Node.js Fastify Supabase PostgreSQL Hedera Firebase SQLite
Voir le showcase sur GitHub

Points clés

  • Détection automatique des fraudes (mouillage, vol de matière sèche)
  • Calcul de la matière sèche (MS) en temps réel
  • Mode offline-first pour les zones rurales
  • Ancrage blockchain SHA-256 sur Hedera
  • 3 rôles : agent de collecte, logisticien, agent de réception
  • Architecture : Flutter + Node.js + Supabase + Hedera + Firebase
